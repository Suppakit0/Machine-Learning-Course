## Dataset Information

The **Aquarium Dataset** used in this project contains images of aquatic animals and is fully annotated in YOLO format. You can download the dataset from the following sources:

- 🌐 **Primary Source:** [Roboflow Universe - Aquarium Dataset](https://universe.roboflow.com/brad-dwyer/aquarium-combined/dataset/2)  
  *(Recommended: You can view the dataset details and export it directly in YOLOv8 format.)*

- 💾 **Backup Download:** [Google Drive Mirror](https://drive.google.com/file/d/15WgD12bTOKZAnnXlfqbwg2sv2pGhfc_z/view?usp=sharing)  
  *(Alternative link: Pre-formatted dataset ready for training.)*
