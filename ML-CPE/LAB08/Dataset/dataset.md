# Dataset Information

* **Primary Source:** [UTKFace Dataset on Kaggle](https://www.kaggle.com/datasets/andrewmvd/animal-faces/data)
* **Backup Download Link:** [Download UTKFace Dataset (Google Drive)](https://drive.google.com/file/d/15uxdhmCW1m9_MYjCBt6D5Y7szc9nUpZo/view?usp=sharing)
* **Description:** A large-scale facial dataset containing images labeled with age, gender, and ethnicity, used for age prediction and gender classification tasks.
